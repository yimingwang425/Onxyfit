# OnyxFit — AI-Powered Fitness & Nutrition Planner

**OnyxFit** is a cross-platform Progressive Web App (PWA) that generates personalised weekly workout and meal plans using a cascade neural network architecture combined with large language model (LLM) integration. Users complete an onboarding profile, and the system produces tailored 7-day fitness and nutrition programmes backed by machine learning predictions and AI-generated recipes.

**Live Demo:** [https://onyx-fit.app](https://onyx-fit.app)

---

## Project Overview

Many fitness applications either provide generic, one-size-fits-all plans or require expensive personal trainer subscriptions. OnyxFit addresses this gap by combining traditional machine learning (TensorFlow/Keras neural networks) with modern LLM capabilities (Llama 3.1 via Groq) to deliver:

- **Personalised macro-nutrient targets** derived from a cascade neural network that considers age, height, weight, activity level, fitness goal, dietary preference, and metabolic profile.
- **7-day meal plans with real recipes** generated by Llama 3.1, each meal containing name, calorie count, macros, ingredients, and step-by-step cooking instructions.
- **Structured workout programmes** (Push/Pull/Legs, Upper/Lower, or Full Body) with exercises, sets, reps, warm-up, and cool-down routines automatically selected based on model output.
- **Daily AI coaching insights** powered by Groq, offering brief personalised tips referencing the user's actual mood, water intake, and training schedule.

## System Architecture

OnyxFit follows a **three-tier microservice architecture**:

```
┌──────────────────────────────────────────────────────────┐
│                    Frontend (PWA)                         │
│          Ionic 8 + Angular 18 + Capacitor                │
│              Deployed on Vercel                           │
└──────────────┬───────────────────────┬───────────────────┘
               │  REST / JSON          │  REST / JSON
               ▼                       ▼
┌──────────────────────────┐ ┌─────────────────────────────┐
│   Backend API Server     │ │   ML Model Service          │
│   Spring Boot 3.3        │ │   Flask + TensorFlow 2.18   │
│   JHipster scaffolded    │ │   + Groq (Llama 3.1)        │
│   Deployed on Railway    │ │   Deployed on Render        │
└──────────┬───────────────┘ └─────────────────────────────┘
           │
           ▼
┌──────────────────────────┐
│   PostgreSQL Database    │
│   Hosted on Neon         │
└──────────────────────────┘
```

| Service            | Platform        |
|--------------------|-----------------|
| Frontend PWA       | Vercel (Free)   |
| Backend API        | Railway (Hobby) |
| ML Model Service   | Render (Free)   |

### ML / AI Service
- **Framework:** Flask 3.0 with Gunicorn
- **Language:** Python
- **Deep Learning:** TensorFlow 2.18 + Keras 3.10 (cascade architecture)
- **Data Processing:** scikit-learn 1.3, NumPy, joblib
- **LLM Integration:** Groq API with Llama 3.1-8B-Instant
- **Model Format:** `.keras` model files + `.pkl` scaler/encoder files

### Infrastructure
- **Domain:** onyx-fit.app (registered via GitHub Student, DNS on Vercel)
- **CI/CD:** Git push triggers auto-deploy on Vercel, Railway, and Render
- **CORS:** Configured in `application-prod.yml` for cross-origin frontend access

## Features

### Authentication & Onboarding
- Email + OTP-based registration (6-digit code via Resend)
- Secure password creation with confirmation
- 7-step onboarding wizard: Name → Age → Height → Weight → Activity Level → Fitness Goal → Diet Preference → Metabolic Profile
- JWT token authentication with route guards
- Password reset flow (from both login and settings pages)
- Email change with OTP verification
- Account deletion with typed confirmation

### Tab 1 — Home (Dashboard)
- **AI Insight Card:** Personalised daily coaching tip generated by Llama 3.1 via Groq, referencing the user's actual workout schedule, mood, and water intake.
- **Weekly Progress:** Doughnut chart + day-of-week dots showing training completion status.
- **Weight Trend:** Sparkline mini chart with expandable overlay showing full weight history.
- **Mood Tracker:** Emoji-based daily mood logging.
- **Water Tracker:** Cup-based intake logging with visual progress dots.

### Tab 2 — Eat (Meal Plans)
- 7-day meal plan with day selector (Sun–Sat)
- Each day contains 4 meals: Breakfast, Lunch, Dinner, Snack
- Every meal displays: dish name, calorie count, macro breakdown (protein/carbs/fat), ingredient list, and step-by-step recipe
- Tap any meal card to view full detail in a slide-up modal
- Calorie targets adjust automatically: training days at full target, rest days at 85%

### Tab 3 — Train (Workout Plans)
- Workout programme automatically selected by the ML model (PPL / Upper-Lower / Full Body Workout)
- Daily view showing: session title, warm-up routine, numbered exercise list (name, sets × reps), cool-down stretches
- Rest day display with motivational messaging
- Tap any workout card to view full detail in a slide-up modal

### Tab 4 — Me (Profile)
- User avatar, display name, and email
- Badge row showing goal, activity level, and diet preference
- Metrics dashboard: programme type, daily calorie target, protein target
- Settings page with: Change email, Change password, Edit profile, Delete account
- Profile check modal that validates completeness before plan generation

## AI / ML Pipeline

### Cascade Neural Network Architecture

The core prediction engine uses a **two-stage cascade model** trained on Google Colab:

```
User Profile Input (7 features)
        │
        ▼
┌─────────────────────┐
│  Workout Model       │  ──→  workout_intensity, workout_type
│  (Keras Dense NN)    │
└────────┬────────────┘
         │ (output feeds as input)
         ▼
┌─────────────────────┐
│  Meal Model          │  ──→  calories, protein, carbs, fat
│  (Keras Dense NN)    │
└─────────────────────┘
```

**Input Features:** age, heightCm, weightKg, activityLevel, goal, dietPref, metabolicProfile

**Preprocessing:** Label encoding for categorical features + StandardScaler for normalisation

**Model Files:**
- `workout_model.keras` — Predicts workout intensity and programme type
- `meal_model.keras` — Predicts daily macro-nutrient targets (cascade input includes workout predictions)
- `scaler_X.pkl`, `scaler_y_workout.pkl`, `scaler_y_meal.pkl` — Feature/target scalers
- `le_activity.pkl`, `le_goal.pkl`, `le_diet.pkl`, `le_metabolic.pkl` — Label encoders

### LLM Meal Plan Generation (Groq + Llama 3.1)

After the neural network predicts macro targets, the Flask service calls the Groq API with Llama 3.1-8B-Instant to generate a complete 7-day meal plan:

1. Neural network outputs daily calorie/protein/carbs/fat targets
2. Targets are adjusted per day: training days at 100%, rest days at 85%
3. A structured prompt is sent to Llama 3.1 requesting 7 days × 4 meals with real dish names, ingredients, and recipes
4. Response is parsed as JSON and returned alongside the numeric predictions

### AI Coaching Insights

The `/api/insight` endpoint accepts the user's current context (today's workout, calorie target, mood, water intake) and prompts Llama 3.1 to generate a single personalised, actionable sentence (under 30 words).

## Design Philosophy

OnyxFit adopts a **Modern Minimalist** design language inspired by Uber and Apple Health:

- **Colour Palette:** High-contrast pure black (#000000) and white (#FFFFFF) with light grey (#F8F9FA) backgrounds.
- **Typography:** Inter font family, 1.8rem/800 ExtraBold headings for visual impact.
- **Input Style:** Borderless rounded inputs with light grey (#F4F5F8) backgrounds.
- **Layout:** Immersive Flexbox layouts with generous whitespace, magazine-style composition on the Welcome page.
- **Interaction:** Subtle scale transforms on touch, smooth slide-up modals, and overlay panels for detailed views.
